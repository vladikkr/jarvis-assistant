Политика конфиденциальности Jarvis

Обновлено: 25 октября 2026.

Кто пользуется приложением

Jarvis — частный ассистент, которым пользуется только его владелец на собственном компьютере.

Какие данные Google используются

  • Gmail: чтение и поиск писем, отметка «прочитано» и отправка писем по команде владельца.
  • Google Календарь: просмотр, создание и удаление событий по команде владельца.

Где хранятся данные

Ключ доступа Google хранится только на компьютере владельца. Письма и события не сохраняются на серверах разработчика и никому не продаются и не передаются. Чтобы ответить на запрос владельца, короткий фрагмент нужного письма или события может передаваться языковой модели, которая формирует ответ.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.
